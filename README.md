# Ember Journal

> A warm, gamified journaling space for daily writing, mood tracking, reflection, and gentle habit building.

**Repository description to paste into GitHub:** `A warm, gamified journaling app with mood tracking, daily writing, streaks, quests, reflections, and insights.`

Ember Journal brings a private daily writing ritual together with mood history, gentle streak motivation, and personal insights. The visual previews below are included in this repository, so GitHub will display them directly on this README page after upload.

## Run the prototype

Open `index.html` in a modern browser. The prototype is a standalone HTML app and does not require a build step or server.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md`, and the `assets` folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Once deployment completes, open the site URL shown in Pages settings.

The feature illustrations appear on the repository's main page through this README. The deployed app itself is served from `index.html`.

## Privacy note

This is a browser prototype. Journal data and preferences are stored locally in the browser; this package does not include a hosted account or backend service.
